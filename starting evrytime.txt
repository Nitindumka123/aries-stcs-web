============================================================
ROLE MODEL
============================================================

There are two initial roles:

ADMIN
SCIENTIST

Operationally, Scientists should eventually be able to use essentially
the same observatory functionality as Admin.

The major difference is DATA PRIVACY.

Scientist:
- can perform observations
- can use telescope functionality
- can use observatory functionality
- can view own observations
- can download own research data
- cannot access another Scientist's private observations/data/files

Admin:
- can perform observations
- can use telescope functionality
- can access observatory functionality
- can view Admin's own observations
- can view permitted/all Scientist observations
- can download permitted/all research data

THIS DATA PRIVACY MUST EVENTUALLY BE ENFORCED BY BACKEND/DATABASE.

Do NOT implement privacy merely by hiding UI buttons.

For Phase 1, establish the authorization architecture so this can
be enforced correctly later.
